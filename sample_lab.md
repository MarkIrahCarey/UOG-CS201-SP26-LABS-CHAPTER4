## Sample Lab: Vowel & Consonant Counter

**Purpose**  
You will read the contents of a text file, then count and classify every character into one of four categories:  
- Vowels (a, e, i, o, u ; case-insensitive)  
- Consonants (all other letters)  
- Spaces (including tabs and newlines if present)  
- Other (punctuation, digits, symbols, etc.)  

After counting, calculate and display:  
- Raw counts for each category  
- Total number of characters  
- Percentage of vowels (vowels / total characters × 100)  

Finally, write a clean summary report to an output file.  

**Requirements**  
- Read the entire contents from an input file called `input_text.txt` 
- Process every character in the file (loop over the string).  
- Use **four integer accumulator variables** to track counts:  
  - `vowel_count`  
  - `consonant_count`  
  - `space_count`  
  - `other_count`  
- Treat vowels case-insensitively (count both 'A' and 'a' as vowels).  
- Spaces include regular spaces (' '), tabs ('\t'), and newlines ('\n').  
- Output to the console (nicely formatted):  
  - Each count  
  - Total characters (vowel + consonant + space + other)  
  - Vowel percentage, rounded to one decimal place (e.g., 28.6%)  
- Write the exact same summary to a new file called `vowel_report.txt` (overwrite if it exists).  
- Include a short header in the output file (e.g., "Vowel & Consonant Report - Generated by [Your Name]").  
- If the file is empty or has no characters, output "No text found" and write the same to the report file.

**Recommended functions/operations**  
- File I/O: `open('input_text.txt', 'r')`, `read()` (to get the whole string at once)  
- String methods: `lower()` (for vowel checking)  
- Loops: `for char in text:` (process one character at a time)  
- Conditionals: `if char in 'aeiou':`, `elif char.isalpha():`, `elif char.isspace():`, `else:`  
- Accumulators: `vowel_count += 1`, etc.  
- Formatting: f-strings or `.format()` for percentages  
- Math: `percentage = (vowel_count / total) * 100` if total > 0, else 0  
- Writing: `open('vowel_report.txt', 'w')`, `write()` or `print(..., file=...)`
